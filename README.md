# 🐍 Python Basics

> A collection of Python exercises and examples created while learning the fundamentals of Python.

## 📚 About

This repository contains beginner-friendly Python programs covering the core concepts of the language. The goal is to build a solid foundation through hands-on practice.

Whether you're just starting your programming journey or reviewing the basics, these examples can help reinforce essential Python concepts.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/picafresaa/python-basics.git
```

Move into the project directory:

```bash
cd python-basics
```

Run any Python file:

```bash
python filename.py
```

or

```bash
python3 filename.py
```
